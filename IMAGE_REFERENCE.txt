  LIMBURG GERMAN CULTURAL CENTER — IMAGE REFERENCE FILE
  ================================================================
  This file lists every image slot in the website.
  For each slot:
    1. Save your photo with the exact filename shown
    2. Place it in the folder shown
    3. Follow the in-code comment to swap the placeholder

  SUPPORTED FORMATS: .jpg  .jpeg  .png  .webp
  RECOMMENDED TOOL: Use https://squoosh.app to compress images
                    before uploading (keeps load time fast).
